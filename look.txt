3. DataTracker поля верблюда
CamelEntity:

DASHING (Boolean)
LAST_POSE_TICK (Long)
Семантика LAST_POSE_TICK:

Отрицательное значение => верблюд сейчас в позе сидя (SITTING).
dataTracker.get(LAST_POSE_TICK) < 0L → isSitting() = true.
Абсолютное значение используется для вычисления дельты времени с последнего начала перехода позы.
getLastPoseTickDelta():

Code
delta = world.getTime() - Math.abs(LAST_POSE_TICK)
Переходные длительности (см. isChangingPose):

Если верблюд сидит (LAST_POSE_TICK < 0) → длительность анимации (standing→sitting) 40 тиков.
Если стоИт → длительность (sitting→standing) 52 тика.
4. Поза: SITTING / STANDING, переходы, логика
Методы:

startSitting():
pose = SITTING
LAST_POSE_TICK = -worldTime (отрицание кодирует «сидит» и момент начала)
Звук: ENTITY_CAMEL_SIT
startStanding():
pose = STANDING
LAST_POSE_TICK = worldTime
Звук: ENTITY_CAMEL_STAND
setStanding():
pose = STANDING
initLastPoseTick(time) → LAST_POSE_TICK = max(0, time - 52 - 1) чтобы “сбросить” переход (верблюд считается уже стабильно стоящим).
Условия смены:

При попытке двигаться (если сидит и не в переходе) — в tickControlled → startStanding().
Если сидит и попал в воду (isTouchingWater) → принудительный setStanding().
shouldUpdateSittingAnimations() проверяет расхождение между знаком LAST_POSE_TICK и результатом isSitting() (фаза перехода).
shouldPlaySittingTransitionAnimation() — если верблюд сидит и delta < 40 и delta >= 0 (первая фаза после начала сидения).

7. Движение, рывок (Dash) и прыжок
7.1. Dash (используется система прыжка AbstractHorseEntity, но переопределено)
Переменные:

dashCooldown (int), стартует = 55 при рывке.
Dashing флаг: DASHING.
Логика в jump(float strength, Vec3d movementInput):

Code
d = HORSE_JUMP_STRENGTH_attribute * jumpVelocityMultiplier + jumpBoostVelocityModifier
horizontal_add = normalize( rotationVector.xz ) * (22.2222f * strength) * movementSpeedAttribute * velocityMultiplier
vertical_add = (1.4285f * strength) * d
velocity += (horizontal_add.x, vertical_add, horizontal_add.z)
dashCooldown = 55
setDashing(true)
Числа:

22.2222f — горизонтальный множитель скорости рывка (по сути ~20 * (1/0.9) масштаб?).
1.4285f — вертикальный множитель (подъём).
jumpStrength параметр (strength) из шкалы зарядки (0..1).
Атрибут Movement Speed (0.09 базово) добавляет масштаб.
Отключение флага Dashing:

Code
if (isDashing() && dashCooldown < 50 && (onGround || touchingWater || hasVehicle()))
    setDashing(false);
→ Dashing активно только первые 5 тиков (когда cooldown от 55 до 50 включительно). После этого визуальная/анимационная часть прекращается, хотя dashCooldown ещё «перезаряжается».

Когда dashCooldown достигнет 0 → звук ENTITY_CAMEL_DASH_READY.

Методы Jump интерфейса:

startJumping(int height) → звук ENTITY_CAMEL_DASH, setDashing(true)
getJumpCooldown() возвращает dashCooldown.

8.2. Посадка пассажиров (updatePassengerPosition)
Индекс пассажира i:
i == 0 (первый) → bl = true
Базовое смещение Z = 0.5f
Если пассажиров > 1:
Второй: f = -0.7f

8.3. Формула method_45346(boolean primaryRider, float partialTicks)
Обозначения:

Code
d = getMountedHeightOffset()
scale = getScaleFactor()
g = scale * 1.43
h = g - scale*0.2
i = g - h = scale*0.2
bl2 = isChangingPose()
bl3 = isSitting()
При переходе:

Общая длительность j:
Если сидит (bl3) → j = 40
Иначе (встаёт) → j = 52
Порог k и коэффициент l:
Если bl3 (сидящий переход – вероятно standing→sitting):
k = 28
l = primaryRider ? 0.5f : 0.1f
Иначе (встаёт):
k = primaryRider ? 24 : 32
l = primaryRider ? 0.6f : 0.35f
m = clamp( lastPoseTickDelta + partialTicks, 0, j )
bl4 = m < k
n2 = bl4 ? m/k : (m-k)/(j-k) (нормированная доля фазы)

o = g - l*h

Далее интерполяции (две фазы: первая до k, вторая после):

Если верблюд садится (bl3):
Code
d += lerp(n2,
          bl4 ? g : o,
          bl4 ? o : i)
Если встаёт:
Code
d += lerp(n2,
          bl4 ? i - g : i - o,
          bl4 ? i - o : 0.0)
После завершения перехода, если сидит и не меняет позу:

Code
d += i
Итогом method_45346 возвращает итоговую добавку высоты посадки для rider.

17. Математика анимаций (общая для Camel через AnimationHelper)
AnimationHelper.animate(model, animation, runningTimeMs, scale, tempVec):

f = runningTimeSeconds = (runningTimeMs / 1000f)
Если animation.looping → f = f % lengthInSeconds
По каждому Transformation:
Ищется i,j ключевые кадры (binarySearch по timestamp)
delta = (f - t_i) / (t_j - t_i) (clamped)
Интерполяция:
LINEAR: линейная
CUBIC: Катмулл-Ром (catmullRom)
Результат умножается на scale (вызов из CamelEntityModel#setAngles даёт scale=1.0)
Target:
TRANSLATE: pivot += vector (но в AnimationHelper createTranslationalVector(y) инвертирует Y: createTranslationalVector(x,y,z) = (x, -y, z)
ROTATE: углы в радианах (createRotationalVector умножает градусы на π/180)
SCALE: xScale+=, yScale+=, zScale+= (не используется в CamelAnimations)

S_m = attr(GENERIC_MOVEMENT_SPEED) (по умолчанию 0.09)
V_base = currentVelocity
dir = normalize( (rotationVector.x, 0, rotationVector.z) )
vmult = getVelocityMultiplier() (обычно 1.0 на суше)
Тогда:

Code
horizontal = dir * (22.2222 * strength * S_m * vmult)
jumpBase = HORSE_JUMP_STRENGTH * jumpVelocityMultiplier + jumpBoostVelocityModifier
vertical = (1.4285 * strength) * jumpBase
V_new = V_base + (horizontal.x, vertical, horizontal.z)
26.2. Изменение угла головы при перезарядке рывка
Пусть:

remaining = getJumpCooldown() - (animationProgress - age)
headPitchClamped = clamp(originalHeadPitch + 45 * remaining / 55, -25, 70)
26.3. Интерполяция посадки пассажира (method_45346)
Обозначим:

Code
scale = s
g = 1.43 * s
h = g - 0.2 * s
i = 0.2 * s
j = (sitting? 40 : 52)
m = clamp(delta, 0, j)
bl4 = m < k
n2 = bl4 ? m/k : (m-k)/(j-k)
o = g - l * h
Case SIT (bl3):
  Yadd = lerp(n2,
              bl4 ? g : o,
              bl4 ? o : i)
Case STAND (else):
  Yadd = lerp(n2,
              bl4 ? (i - g) : (i - o),
              bl4 ? (i - o) : 0)
If steady sitting (no transition):
  Yadd += i
Result height = mountedHeightOffset + Yadd
26.4. MountedHeightOffset
Code
baseHeight = (pose == SITTING ? sittingDimensions.height : standingDimensions.height)
mountedOffset = baseHeight - (isBaby ? 0.35 : 0.6)

27. Отличия от лошадей
Главные уникальные особенности Camel по сравнению с AbstractHorseEntity:

Две позиции (сидит / стоит) с длинной анимацией изменения высоты корпуса.
Возможность везти двух пассажиров (позиционирование второго смещено назад и ниже).
Рывок (dash) со своей отдельной короткой анимацией и cooldown 55 (у лошадей — заряженный прыжок, но нет управления горизонтальным множителем 22.2222).
Сидячее состояние блокирует движение и поворот головы сверх 30°.
Breeding item – кактус (у стандартных лошадей другой список).
Всегда isTame() == true (лошадь требует приручения; Camel переопределяет isTame, возвращая true).
Специальные звуки верблюда.
Специальная логика перехода позы через знак LAST_POSE_TICK.
28. Прочие моменты
При повреждении верблюд автоматически встаёт (setStanding() в applyDamage).
При слишком длинном поводке (leashLength > 6) в сидячем состоянии — встаёт.
Смена состояния дашинга на клиенте синхронизируется через DataTracker; при первом получении DASHING (если dashCooldown==0) устанавливается 55.
